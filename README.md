#Zona Fluxus WEB

Sistema Web full stack, desenvolvido para fim de estudo e portfólio

##Stack

-React
-TypeScript
-Node.js
-PostgreSQL
-Primsa ORM
_JWT
-Docker

##Objetivo

Construir uma aplicação completa, seguindo boas práticas de arquitetura, versionamento, e desenvolvimento profissional, utilizando IAs como auxiliadoras durante o processo fazendo papel de:

-Apresentar alternativas;

-Explicar os prós e contras de cada uma;

-Apontar riscos que possam passar despercebidos;

-Questionar decisões quando  possíveis problemas forem detectados;

-Ajudar a validar a arquitetura;

-Revisar código e sugerir melhorias;

-Explicar conceitos quando necessário.
